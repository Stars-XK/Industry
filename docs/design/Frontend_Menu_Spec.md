# 信创工业综合治理平台 - 前端菜单与页面功能设计规范（深度关联版）

本规范在基础菜单结构的层面上，严格定义了每个页面的**具体UI元素**、**核心操作按钮**，以及最关键的**【跨模块数据与业务联动关联】**。它是后续前后端 API 设计与数据库表结构关联的直接依据。

---

## 1. 登录与门户体系

### 1.1 统一登录页 (Login)
- **【具体功能】**：提供高安全性、防暴力破解的政企级登录入口。
- **【UI交互与操作】**：
  - 账号密码输入框、手机短信验证码切换 Tab、企业微信/钉钉扫码区。
  - 连续输错 5 次后自动弹出**图形滑动/行为验证码**。
- **【模块联动关联】**：
  - -> 关联【RBAC 权限中心】：登录成功后，系统请求权限接口，动态渲染左侧菜单树与页面内按钮的可见性。
  - -> 关联【安全审计日志】：将每一次登录尝试（成功/失败、IP、浏览器指纹）写入审计库。

### 1.2 沉浸式数字孪生大屏 (Digital Twin Dashboard)
- **【具体功能】**：基于 WebGL/Three.js 构建的厂区 3D 监控中心，提供一图统管与空间分析能力。
- **【UI交互与操作】**：
  - **地图工具栏**：右上角提供“底图切换（高德/自建GeoServer）”、“图层控制（隐藏管线/显示设备）”、“测距与面积分析”工具。
  - **报警联动聚焦**：发生报警时，地图自动 Zoom-in 平移至故障点，节点标红闪烁，点击弹出现场监控视频弹窗与【快捷反控】面板。
  - **爆管关阀推演弹窗**：在爆管点右键点击【关阀分析】，侧边栏弹出“推荐关闭阀门列表”及“受停水影响区域名单”。
- **【模块联动关联】**：
  - -> 关联【资产与设备台账】：大屏上的每一个 3D 模型节点，点击均能拉取并展示该设备的台账信息与历史维修记录。
  - -> 关联【在线水力模型】：关阀分析结果并非写死，而是实时调用底层 EPANET 模型接口，计算连通性后返回给前端渲染。
  - -> 关联【工单管理】：大屏弹窗内可直接点击【一键派单】，将故障点坐标 (Lng, Lat) 带入并生成抢修工单。

## 2. 综合业务监控台 (SCADA & Monitor)

### 2.1 全局态势感知 (Overview Dashboard)
- **【具体功能】**：厂区/全区核心运营指标的 2D 数据看板。
- **【UI交互与操作】**：
  - 顶部提供时间范围筛选器（今日、本周、本月）。
  - 卡片式展示：总供水、总售水、整体产销差率、总能耗折标煤。
  - 嵌套 Echarts 水质仪表盘（浊度、余氯、pH）。
- **【模块联动关联】**：
  - -> 关联【营收计费模块】：卡片上的“总售水”数据并非来自底层水表，而是调用营收模块的清洗折算接口。

### 2.2 工业 SCADA 工艺组态 (SCADA HMI)
- **【具体功能】**：车间、泵房等微观生产场景的 2D/2.5D 监控与反控。
- **【UI交互与操作】**：
  - **动态组态画面**：展示液位升降、电机旋转、水流颜色渐变。
  - **控制面板弹窗**：点击特定水泵图元，弹出【启/停】按钮及【频率设定】滑块。
  - **写前校验与二次确认**：点击“启泵”后，弹出二次确认框，需输入操作密码或插入 U-Key。
- **【模块联动关联】**：
  - -> 关联【低代码组态工作台】：此页面的所有图纸均由组态工作台绘制并发布过来。
  - -> 关联【测点标签管理】：图元绑定的变量（如 `PUMP_01`）直接映射到底层网关的寄存器配置。
  - -> 关联【安全审计日志】：所有的下发指令必须记入审计日志，包含操作前状态与期望状态。

## 3. 多维统计与数据分析 (Data Analytics)

### 3.1 DMA 产销差与漏损报表 (NRW & Leakage Reports)
- **【具体功能】**：严格按照国际水协 (IWA) 标准，展示分区水量平衡表与漏损率。
- **【UI交互与操作】**：
  - **顶部条件栏**：时间选择器、**拓扑时间切片选择器（版本号/日期）**。
  - **Sankey 流向图**：动态绘制 100% 供水如何分流为售水、未计费水和漏水。
  - **穿透式数据表**：点击父分区（如“一厂区”），行内展开其下属车间的明细数据。
  - **导出与比对按钮**：提供【导出 Excel】及【同环比曲线比对】操作。
- **【模块联动关联】**：
  - -> **关联【营收计费模块 - 资产户号映射】（核心痛点）**：产销差计算的前提，是依赖映射表将“营收系统的客户水表号”挂载到对应的“DMA 分区节点”上，否则无法计算售水量。
  - -> 关联【未计费水量冲销审批】：报表中的“未计费水量”列，数据来源于外勤提报并审批通过的冲销工单汇总。
  - -> 关联【时空拓扑切片】：查询历史漏损时，系统根据顶部选择的时间切片，向拓扑引擎请求当时的管网从属关系进行结算。

### 3.2 夜间最小流量分析 (MNF Analysis)
- **【具体功能】**：提取凌晨低谷数据进行暗漏排查，并利用大户数据剥离合法夜间用水。
- **【UI交互与操作】**：
  - 散点图展示每日 2:00-4:00 流量，红线标识 AI 动态基线。
  - 提供【合法大户夜间用量剥离】开关按钮，开启后图表自动重绘。
  - 对于连续 3 天超标的分区，列表右侧提供【生成听漏工单】按钮。
- **【模块联动关联】**：
  - -> 关联【大户档案监控】：点击剥离开关时，系统向大户模块请求该分区内连续生产企业的夜间用量总和并予以扣除。
  - -> 关联【工单管理】：生成的听漏工单直接流入外勤工单池。

### 3.3 大用户与重点企业画像 (Key Account)
- **【具体功能】**：高耗水/高排污大户的监控，挽回“大表小用”造成的营收流失。
- **【UI交互与操作】**：
  - 大户台账列表（展示行业、合同限额、信用评级）。
  - **异常诊断面板**：展示水表口径与流量的匹配度曲线，红框标出“始动流量下不计费”的时段。
  - 操作列提供【生成水表降级建议单】及【发起追缴单】按钮。
- **【模块联动关联】**：
  - -> 关联【营收计费管理】：追缴单直接推送给营收财务人员进行跟进；大户的信用评级影响其下月的预付费策略。
  - -> 关联【备品备件仓储】：若建议换表，可点击查看当前仓库是否有对应小口径水表的库存。

## 4. 营收对账与财务联动 (Billing & Reconciliation)

### 4.1 营收字典与“户号-DMA”映射台 (Account-DMA Mapping)
- **【具体功能】**：解决供售水脱节的核心页面，建立营收台账与 SCADA 物理拓扑的桥梁。
- **【UI交互与操作】**：
  - 左侧展示 SCADA 系统的 DMA 物理分区树。
  - 右侧提供待分配的“营收计费系统客户户号/水表号”列表。
  - 支持拖拽或勾选，将营收户号强绑定至对应的 DMA 分区。
- **【模块联动关联】**：
  - -> 关联【数据中台清洗引擎】：流计算引擎根据此映射关系，将离散的售水账单精准归集到对应的 DMA 分区总账中。

### 4.2 阶梯费率与自动出账单 (Billing & Rate)
- **【具体功能】**：配置水/电费率并自动生成对账单凭证。
- **【UI交互与操作】**：
  - **费率库配置**：通过动态表单配置“第一阶梯 0-100吨 3元/吨”、“第二阶梯 >100吨 4.5元/吨”、“污水处理费代收比 0.8”。
  - **对账单列表**：按月展示各企业的电子对账单，提供【导出 PDF】及【标记已核销】按钮。
- **【模块联动关联】**：
  - -> 关联【外部财务系统】：本系统不直连支付，仅提供标准 API 供财务 ERP（如金蝶/用友）抓取出账单，财务系统核销后回调接口更新“标记已核销”状态。

## 5. 运维治理与工单闭环 (O&M & Workflow)

### 5.1 报警收敛与规则引擎 (Alarm & RCA)
- **【具体功能】**：配置报警风暴压制规则，展示高信噪比报警。
- **【UI交互与操作】**：
  - **报警收敛规则配置**：下拉选择拓扑节点，配置“若 3 分钟内同一分支下报警数 > 5，则合并为父级报警”。
  - **综合报警看板**：列表展示报警，提供【确认(ACK)】、【消音】、【转工单】按钮。
- **【模块联动关联】**：
  - -> 关联【SCADA 报警联锁】：部分严重报警触发的同时，会联动底层联锁配置（如关停泵），该页面需同时展示联锁动作执行结果。

### 5.2 工单与 SOP 应急流转 (Work Order & SOP)
- **【具体功能】**：外勤人员的抢修、巡检及未计费水量冲销流转。
- **【UI交互与操作】**：
  - **SOP 预案配置面板**：以流程图（类似钉钉审批流）形式拖拽配置“爆管预案”的执行步骤。
  - **工单看板**：Kanban 视图拖拽更改工单状态，提供【领料登记】和【上传验收照片】操作。
- **【模块联动关联】**：
  - -> 关联【备品备件仓储】：点击【领料登记】时，弹出库存列表供勾选扣减。
  - -> 关联【排班与定位】：派单时，系统根据“当前值班表”和“GIS 实时人员定位”，在下拉框中优先推荐距离最近的在岗人员。

## 6. 底层配置与数据中台 (Data Governance)

### 6.1 边缘网关与协议模板 (Gateway & Protocols)
- **【具体功能】**：底层物联网设备接入配置台。
- **【UI交互与操作】**：
  - **协议模板库**：维护 Modbus RTU/TCP、OPC UA 协议的解析脚本。
  - **网关配置下发**：提供【下发串口配置】按钮，向指定边缘树莓派下发波特率、寄存器地址表。
- **【模块联动关联】**：
  - -> 关联【测点标签管理】：网关解析出的寄存器数据，下一步将流向标签管理页面进行全局唯一 Tag 映射。

### 6.2 离散数据清洗与插值规则 (Data Interpolation)
- **【具体功能】**：配置针对低频水表数据的算法，解决脏数据。
- **【UI交互与操作】**：
  - 提供表单配置：选择插值算法（PCHIP/线性）、配置“最大物理流速阈值”（用于剔除毛刺）。
  - **错期分摊任务配置**：配置营收账单平摊到每日的权重策略（按平均天数或按历史供水趋势）。
- **【模块联动关联】**：
  - -> 关联【资产与设备台账】：当台账中发生“换表操作”时，本页面的清洗引擎会自动捕获新老表底码，执行接续算法。

## 7. 仓储、资产与系统设置 (Inventory & System)

### 7.1 备品备件与仓储管理 (Inventory)
- **【具体功能】**：管理阀门、药剂等耗材库存。
- **【UI交互与操作】**：
  - 库存列表页，包含【入库】、【报损】、【设置安全库存线】按钮。
  - 低于安全库存时行级标红告警。
- **【模块联动关联】**：
  - -> 关联【工单管理】：物料消耗唯一出口为“工单领料”，实现物料成本与维修事件的 100% 挂钩。

### 7.2 角色与权限体系 (RBAC)
- **【具体功能】**：配置系统访问权限。
- **【UI交互与操作】**：
  - **菜单/按钮授权树**：勾选左侧菜单及页面内特定按钮。
  - **数据隔离策略下拉框**：选择“仅本人/本部门/特定 DMA”。
- **【模块联动关联】**：
  - -> 关联【所有页面】：决定了登录人员能看到哪些菜单、是否能点击“强制关阀”等特权按钮。
